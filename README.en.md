**AI advances the task. You escort the mission.**

Whileplay is a task-linked arcade plugin for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). Your conversation's Todos become island waypoints, tool calls bring interceptors and supplies, completed subagents join your flight, and delivered files board the transport ship. Move, shoot, dodge, and protect the convoy while AI works.

For a quick round, choose Air Battle, Tank Battle, or Snake, with tool-driven targets and supplies from completed task steps.

Keep playing while AI works. When the conversation stops running or needs your input, the game pauses so you can return to it.

## Why try Whileplay?

- **Each task has its own journey.** The mission title, Todos, subagent flight, and cargo manifest follow your current conversation. Missing data stays visibly empty.
- **Real-time action you control.** Move in four directions, fire automatically, dash through danger, repair the convoy, and call air support. Game outcomes never control AI execution.
- **Put the game where you want it.** Move and resize the floating window. The three classic games also offer a compact, game-only mode.
- **Return when you are needed.** The game pauses when the conversation stops running, awaits approval, or asks for input. Resume the round when you are ready.
- **Try it right after installation.** All four games include a demo requiring no model setup. Classic games support Chinese and English with light and dark themes; Convoy Escort currently has a Chinese interface.

## Quick start

You need DeepSeek Harness with its Web profile, Node.js `^22.19.0 || >=24.0.0`, and npm. The current release has been verified with Harness `0.2.1-alpha.4`; other host versions have not been verified.

### Install the current source version

This page describes the current `main` branch. **Convoy Escort, Air Battle growth paths, and session checkpoints are not included in the v0.2.0 Release.** Build from source to try these features:

```sh
git clone https://github.com/monster-cli/dsh-whileplay.git
cd dsh-whileplay
npm ci
npm pack
dsh plugin --profile web add ./dsh-whileplay-0.2.0.tgz
dsh web
```

The source package still uses version `0.2.0`; install the file generated by your local `npm pack`. Restart any running Web profile after installation.

### Install the published release

**1. Download the plugin.** The [v0.2.0 package](https://github.com/monster-cli/dsh-whileplay/releases/download/v0.2.0/dsh-whileplay-0.2.0.tgz) includes three classic games with tool and Step integration.

**2. Install and start.** Run these commands in the directory containing the package:

```sh
dsh plugin --profile web add ./dsh-whileplay-0.2.0.tgz
dsh web
```

Restart the Web profile after installation if Harness Web is already running.

### Start playing

Open the **complete URL** printed by `dsh web` to authenticate the browser. Click **“◈ Play a little”** beside the chat composer, choose a game, and start playing. Without a running task, choose **“Try task escort”** to explore targets and supplies immediately.

For live integration, configure your provider credentials in DSH **Settings → Models**, select a model, and run a task. Whileplay follows the current **DSH conversation**, not tasks in other applications, and makes no additional model calls.

## Convoy Escort: your current task on the battlefield

Escort a transport ship past islands and reefs while protecting it from enemy attacks. Movement, automatic targeting, dodging, and supply collection form a continuous action game. Task details appear both on the battlefield and in the mission briefing.

| What happens in your task | What happens in the game |
| --- | --- |
| Todos are created or updated | Waypoints show real Todo titles and statuses; the route follows task progress |
| A tool is called | An interceptor labeled with the tool name enters; its flight continues after the tool returns |
| A tool succeeds / a Step ends | Firepower / shield supplies arrive for you to collect |
| A subagent completes its work | Subagents confirmed complete in the current turn provide up to two wingmen |
| Files are presented for delivery | The transport displays their filenames; ordinary file writes do not count as delivery |
| The conversation stops or needs input | The battlefield pauses so you can return; stopping alone does not mean the task succeeded |

The default **当前会话 (Current conversation)** mode uses real data, with explicit empty states for missing Todos, subagents, or deliveries. Switch to **联动演练 (Demo)** to play the complete Pomodoro-site example. The two modes are clearly labeled and save separately.

**Controls:** `WASD`, arrow keys, or dragging to move; automatic fire; `Space` to dash; `Q` to spend repair support; `E` to spend air support; `Escape` to pause. Energy pickups upgrade firepower and combos increase points. Losing the aircraft or transport ends the round without affecting the real task.

## Three games, three ways to play along

| Game | Classic gameplay | Targets from tool calls | Supplies from completed steps |
| --- | --- | --- | --- |
| **Air Battle** | Move in all four directions and fire automatically | Scanner bursts, transport cargo, armor weak spots, charged cannons | Twin shot, shield, bomb, and a choice of growth upgrades |
| **Tank Battle** | Break through bricks, navigate steel walls, and defend your base | Armored enemy tanks that take three hits | Rapid fire, shield, battlefield bomb |
| **Snake** | Eat, grow, and avoid the walls and your own body | Timed bonus fruit labeled with tool names | Double score, shield, slow motion |

Once spawned, task targets follow the game's rules until defeated, collected, or gone. Game outcomes and task execution are independent. Air Battle shows at most two tool targets at once; bursts of calls wait their turn.

### Controls

- **Air Battle:** use the arrow keys or drag on the canvas to move. Your aircraft fires automatically. Catch one upgrade capsule, click an upgrade button, or press `1` / `2` to choose.
- **Tank Battle:** use the arrow keys to move and turn, and `Space` to fire. Bricks can be destroyed; steel blocks shots. Opposing bullets cancel each other out. You have three lives; losing them or losing the base ends the round.
- **Snake:** use the arrow keys to turn and collect food and bonus fruit.

Click the canvas to use keyboard controls. The window also provides direction and fire buttons. Press `Escape` to collapse it.

### Air Battle: a different approach to each task

Search scanners telegraph fan-shaped bursts. Damaging a read transport's cargo releases a supply. Engineering aircraft have side weak spots and periodically open their armor. Command aircraft lock a position before firing a charged cannon. Spawned targets follow their own game rules regardless of when the tool returns.

Completed Steps gradually unlock two-option upgrades alongside regular supplies. **Firepower** grows from twin shot to spread and piercing bullets. **Survival** adds a shield, shield regeneration, and one emergency rescue. **Mobility** increases speed and eventually rewards near misses with points and charge. Missed upgrade capsules remain claimable through the buttons. Each path has three levels; later choices require more Steps.

Dense tool activity enters as pairs with a gap between formations. Calls beyond the visual queue become limited extra supplies, while ordinary aircraft keep the field active between tool events. The Air Battle rehearsal includes all four archetypes, dense formations, supplies, and growth choices, and can be paused anytime.

### Catch a power-up. Change the round.

Every completed AI step sends a supply worth an extra +20 points when collected. Aircraft supplies drift downward, tank supplies appear in reachable open lanes, and Snake supplies appear on free cells. Tank and Snake supplies, and bonus fruit, remain for 12 seconds.

| Power-up | Effect |
| --- | --- |
| **Twin shot / rapid fire / double score** | Boosts aircraft firepower, tank firing rate, or Snake scoring for 8 seconds. Collecting another refreshes the duration. |
| **Shield** | Absorbs one hit and does not stack. Snake tries to turn into an adjacent safe cell; the round still ends if no safe turn exists. |
| **Bomb** | In Air Battle, clears enemy shots, destroys ordinary aircraft, and deals 6 damage to bosses. In Tank Battle, clears enemy shots and tanks while preserving walls and the base. |
| **Slow motion** | Slows Snake for 8 seconds, giving you more time to turn. |

Destroying a tool aircraft awards +100 points; an armored tool tank, +200. Tool fruit awards +30 and grows the snake by one cell. Snake's double-score effect applies to ordinary food, tool fruit, and supply pickups. Supply lifetimes and active effects freeze while paused.

## A small window, an easy return to work

- **Move and resize:** drag the title bar or dotted handle to move the window; drag any edge or corner to resize it. Adjusting the window pauses the game. Click “Resume” when ready.
- **Minimal mode (classic games):** hide the library, heading, and toolbar, leaving just the game. Hover to reveal move, pause, and restore controls. These controls stay visible on touch devices.
- **Automatic pauses:** the game pauses when the conversation stops running, awaits approval or input, or its status becomes unavailable. Leaving the browser window or hiding the page also pauses it. Resume manually when you return.

Air Battle keeps the eight most recent session checkpoints in your current browser, including the field, supplies, upgrades, and rehearsal progress. After switching games or conversations, or refreshing, resume manually with a short preparation period. Restarting the round or rehearsal replaces that session's Air Battle checkpoint. A message appears if browser storage is unavailable.

Tank Battle and Snake preserve progress while collapsed on the current page; switching games or conversations, or refreshing, starts a fresh round. Refreshing resets window layout. Best scores stay in the current browser. A task ending pauses the game and displays a summary: return to the conversation, then continue Air Battle later.

Convoy Escort saves live play and demo progress separately for each session and resumes manually after refresh. Real request summaries, Todo text, subagent names, and delivery filenames are not written to game checkpoints. Tool arguments, outputs, and file contents do not enter the game.

## FAQ

**Do I need a model or API key?**

The games and task-escort demo need neither, and make no additional model requests. For live task-linked play, configure and run an AI task as you normally would in DeepSeek Harness.

**Why is “Try task escort” disabled?**

The three classic games disable demos while the conversation is running or awaiting input, and automatically follow a real task when it starts. Convoy Escort uses an explicit Current conversation / Demo switch. Both escort modes pause when the real conversation needs your input.

**What do “authentication required” and “no API key” mean?**

The first concerns browser access: reopen the complete URL printed when `dsh web` starts. The second means model credentials are missing: save the appropriate provider's API key in **Settings → Models**, select a model, and send the task again. A separate `DSH_HOME` data directory needs its own credential configuration.

**How do I upgrade or uninstall?**

To upgrade, download the new `.tgz`, run the installation command again, and restart the Web profile. To uninstall, run the command below, then restart the Web profile:

```sh
dsh plugin --profile web remove dsh-whileplay
```

If you run Harness through npm, use `npx @deepseek-ai/dsh plugin --profile web remove dsh-whileplay`. Uninstalling does not automatically clear best scores stored in your browser.
