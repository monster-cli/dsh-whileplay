# v0.4.0 · 动静皆宜 / A move between replies

## 新增国际象棋与五子棋

游戏库新增「棋类」分类，现在共六款游戏。两款棋类支持本地人机对弈和同屏双人，无需 API Key，不额外调用模型。

- **国际象棋**：合法落点提示、将军与将杀、王车易位、吃过路兵、四种升变及和棋判定；人机模式玩家执白先行，电脑定位为休闲对手。
- **五子棋**：15×15 自由规则，五连或长连获胜，无禁手；玩家执黑先行，电脑会争胜并防守直接威胁。
- 棋谱、最后一手标记、悔棋、按会话自动存档，以及中英文界面和极简模式。
- 人机对弈区分胜利与落败，双人模式显示获胜方，和棋独立展示；结算提供「再来一局」「查看棋盘」与重新查看结算的入口。
- 会话结束、需要用户操作或页面失焦时暂停；工具调用不会改变棋盘规则或代替玩家落子。

## 体验修复

- 游戏库、棋类与小队护送远征共用窗口位置和尺寸；切换页面不再左右跳动，返回游戏库保留拖动、缩放后的布局。
- 未结束的棋局重开前，在窗口中央确认，解决确认内容被挤出可见区域的问题。确认后直接开局，取消或 Esc 保留原局。
- 重开或暂停时取消尚未执行的电脑应手，避免旧棋局的落子进入新局。
- 修正宿主圆角样式对五子棋棋子的影响，保持圆形棋子。

## 安装与升级

下载本 Release 的 [dsh-whileplay-0.4.0.tgz](https://github.com/monster-cli/dsh-whileplay/releases/download/v0.4.0/dsh-whileplay-0.4.0.tgz)，在安装包所在目录执行：

```sh
dsh plugin --profile web add ./dsh-whileplay-0.4.0.tgz
dsh web
```

安装后重启已运行的 Web profile，使用启动时输出的完整 URL 打开页面。已有游戏存档不会主动清除。

## English

- Adds Chess and Gomoku, bringing the library to six games. Both offer a casual local computer opponent and same-device two-player mode without model calls.
- Chess supports legal move hints, checkmate, castling, en passant, promotion, and draws. Gomoku uses freestyle 15×15 rules: five or more in a row wins, with no forbidden moves.
- Includes undo, move history, session saves, Chinese and English UI, minimal mode, and distinct win/loss/draw screens with rematch and board review.
- Keeps window position and size consistent between the library, board games, and Convoy Escort.
- Centers restart confirmation, starts the new round immediately after confirmation, and cancels stale computer moves.
- Download the attached `dsh-whileplay-0.4.0.tgz`, install using the commands above, then restart the Web profile. No source checkout or build is required.
