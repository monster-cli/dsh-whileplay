# v0.2.0 · 玩一小局 / Whileplay

三款小游戏现在都能与 DeepSeek Harness 的任务执行联动：工具调用带来敌人或奖励目标，Step 结束带来道具。游戏操作不会影响任务执行。

## 新功能

- **飞机大战**：支持上下左右移动和拖动；工具调用生成不同类型的小 Boss，入场后持续飞行和投弹，直到被击落或飞出画面，工具完成或失败不会触发退场。Step 补给包含双发子弹、护盾和清屏炸弹。
- **坦克大战**：工具调用生成需要命中三次的精英坦克；Step 补给包含连发、护盾和战场炸弹。道具生成在玩家可达的空闲通道，炸弹保留墙体与基地。
- **贪吃蛇**：工具调用生成带工具名称的限时奖励果实；Step 补给包含双倍得分、护盾和减速。护盾可消耗一次并尝试转向安全格；奖励果实不会挤占普通食物所需的最后空格。
- **联动演练**：三款游戏均提供本地演练，展示工具目标、Step 补给、失败与再次调用，无需 API Key，不发送模型请求。
- **任务状态**：按会话与轮次隔离事件，历史事件不补发奖励，密集调用和补给排队入场；任务结束后暂停并显示结算，暂停期间道具时间冻结。
- README 更新三款游戏的联动规则、道具效果、演练和安装说明。

## 下载、安装与升级

下载本 Release 附件 **dsh-whileplay-0.2.0.tgz**，在文件所在目录执行：

```sh
dsh plugin --profile web add ./dsh-whileplay-0.2.0.tgz
dsh web
```

已有 v0.1.0 的用户执行同一条安装命令，然后重启 Web profile。通过 npm 运行 Harness 时，可以将 `dsh` 替换成 `npx @deepseek-ai/dsh`。

打开 Harness 页面，点击聊天输入框旁的「◈ 玩一小局」。选择游戏后可直接点击「联动演练」体验。直接安装请使用 `.tgz` 附件；GitHub 自动提供的 Source code 压缩包用于源码开发。

## 兼容性与验证

- Node.js：`^22.19.0 || >=24.0.0`。
- 已验证宿主：DeepSeek Harness `0.2.1-alpha.4`，源码提交 `86a40220`；其他宿主版本尚未验证。
- 50 项游戏规则、联动、道具、窗口和客户端测试通过。
- 真实 Harness 页面回归通过，覆盖三款游戏及坦克、贪吃蛇演练。
- 真实 Session 事件、工具与 Step 投影、变化通知和插件卸载检查通过。
- 从生成的 `.tgz` 独立安装后，宿主入口与依赖导入、真实 Harness 页面回归均通过。
- 安装包包含 README、MIT LICENSE，以及所需的宿主和客户端入口；安装时会解析声明的 Zod 依赖。

工具执行状态来自宿主的只读事件投影，不包含工具参数、工具输出或会话正文；游戏不会向模型或工具发送请求。
