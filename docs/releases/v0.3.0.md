# v0.3.0 · 任务成为航程 / Escort your task

## 新增小队护送远征

驾驶战机护送运输船穿过岛屿与礁石：四向移动、自动锁敌、闪避冲刺、工程修复和空袭支援组成实时战斗。

- 默认跟随当前 DSH 会话，显示真实任务请求、Todo、子 Agent 和交付文件。
- Todo 成为航程节点；工具调用带来具名拦截机，成功返回投放火力补给，Step 结束投放护盾。
- 确认本轮完成的子 Agent 提供最多两架僚机；明确呈交的文件显示在运输船清单中。
- 工具目标入场后按游戏规则行动，工具返回不会使它消失。任务停止或等待用户处理时暂停战场，不推定任务成功。
- 保留独立的「联动演练」，无需模型即可体验番茄钟小站示例；真实模式没有任务数据时显示空态。
- 竖向海面、岛屿航点、金属战机与货船、任务电台和编队标签；窗口支持移动和缩放。

## 飞机大战升级

- 四种工具敌机：扫描弹幕、运输货舱、装甲弱点与蓄力重炮。
- Step 解锁火力、生存、机动三条成长路线，每条最多三级；升级提供二选一操作。
- 密集调用按双机编队入场，等待容量之外的调用折算为有限补给。
- 按会话保存最近八份飞机存档，包括战场、道具、升级和演练进度；恢复需手动继续。

远征的真实模式与演练也按会话分别保存。游戏胜负不会改变任务执行或权限决定，插件不额外调用模型。

## 安装与升级

下载本 Release 的 `dsh-whileplay-0.3.0.tgz`，在文件所在目录执行：

```sh
dsh plugin --profile web add ./dsh-whileplay-0.3.0.tgz
dsh web
```

已有 Web 服务运行时请安装后重启。使用启动时输出的完整 URL 完成浏览器认证；真实任务需要在「设置 → 模型」中配置模型凭据。升级不会主动清除浏览器中的游戏存档。

## Compatibility and highlights

- Adds Convoy Escort: real-time movement, automatic fire, dashing, repairs, and air support around your current DSH task.
- Real Todos become waypoints, tool activity brings interceptors and supplies, completed subagents provide wingmen, and presented files board the convoy.
- Keeps live play separate from the optional model-free demo. Missing data is never replaced by the example task.
- Air Battle gains four tool enemy archetypes, three growth paths, paced formations, and session checkpoints.
- Classic games support Chinese and English; Convoy Escort currently uses Chinese. Minimal mode remains available for the classic games.
- Download the attached `.tgz`, run the installation command above, and restart the Web profile. Game outcomes do not affect task execution; the plugin makes no model calls.
