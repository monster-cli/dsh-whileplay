# 玩一小局 · Whileplay

在 DeepSeek Harness 等待 AI 回复时，随手玩一小局。

内置飞机大战、坦克大战和贪吃蛇。游戏运行在可移动、可缩放的悬浮窗口中，也可以切换成只显示游戏画面的极简模式。

任务执行时，工具调用带来敌人或奖励目标，AI 每完成一步（Step）就送来道具。没有任务时，也可以直接开始游戏或体验「联动演练」。

## 效果展示

从聊天输入框旁打开「玩一小局」，体验三款游戏的任务联动与丰富道具。

![玩一小局：三款游戏的任务联动与道具](docs/assets/whileplay-v0.2.0-demo.gif)

## 安装与启动

### 环境要求

- 已安装 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)，使用 Web profile。
- Node.js `^22.19.0 || >=24.0.0` 与 npm。
- 目前已在 DeepSeek Harness `0.2.1-alpha.4` 上验证，其他版本尚未验证。

### 1. 下载安装包

下载 **[dsh-whileplay-0.2.0.tgz](https://github.com/monster-cli/dsh-whileplay/releases/download/v0.2.0/dsh-whileplay-0.2.0.tgz)**。

更新内容见 [v0.2.0 Release](https://github.com/monster-cli/dsh-whileplay/releases/tag/v0.2.0)。

### 2. 安装到 Web profile

在安装包所在目录打开终端，执行：

```sh
dsh plugin --profile web add ./dsh-whileplay-0.2.0.tgz
```

已安装旧版时，也可使用这条命令升级，安装后重启 Harness。

通过 npm 运行 Harness、没有全局 `dsh` 命令的用户，使用：

```sh
npx @deepseek-ai/dsh plugin --profile web add ./dsh-whileplay-0.2.0.tgz
```

### 3. 打开游戏

启动或重启 Harness Web profile：

```sh
dsh web
```

通过 npm 运行 Harness 时使用 `npx @deepseek-ai/dsh web`。

打开终端输出的页面，点击聊天输入框旁的 **「◈ 玩一小局」**，选择游戏，再点击「开始游戏」。

## 三款小游戏

| 游戏 | 操作 | 玩法 |
| --- | --- | --- |
| 飞机大战 | 上下左右方向键，或在画布上拖动 | 自动发射子弹，普通敌机 +10 分，工具小 Boss +100 分 |
| 坦克大战 | 方向键移动转向，空格射击 | 击毁敌坦克每辆 +100 分，守卫底部基地 |
| 贪吃蛇 | 方向键转向 | 吃食物增长，避开边界和自己 |

坦克大战包含砖墙、钢墙和敌方坦克。砖墙可以逐块击碎，钢墙不可破坏，双方子弹可以互相抵消。玩家有 3 条生命，受击重生后短暂无敌；生命耗尽或基地被任意一方的子弹击毁时结束。

游戏库支持搜索与分类，窗口和画布跟随 DSH 的浅色、深色主题。画布获得焦点后响应键盘操作，Escape 收起游戏窗口。

## 任务变成游戏的一部分

当前会话执行任务时，三款游戏会出现各自的目标与补给：

| 游戏 | 工具调用带来的目标 | Step 结束带来的道具 |
| --- | --- | --- |
| 飞机大战 | 按工具类型生成轰炸机、运输机或装甲机，可投弹、可击落 | 双发子弹、护盾、清屏炸弹 |
| 坦克大战 | 从空闲入口驶入三血精英坦克，击毁 +200 分 | 连发、护盾、战场炸弹 |
| 贪吃蛇 | 在空白格生成带工具名称的限时果实，吃到 +30 分并增长一格 | 双倍得分、护盾、减速 |

敌人和奖励目标出现后，会一直参与本局，直到被击败、收集或按游戏规则离场。任务状态单独更新，游戏操作不会影响任务执行。工具目标同时最多两个，密集调用依次入场。

AI 每完成一步，就会送来一份补给，需要主动接住，拾取额外 +20 分。飞机道具向下飘落，坦克道具出现在可达的空闲通道，贪吃蛇道具出现在空白格。坦克与贪吃蛇的道具、工具果实保留 12 秒，记得及时收集。

- **飞机双发 / 坦克连发 / 贪吃蛇双倍得分**：持续 8 秒，重复拾取刷新时长，不叠加。贪吃蛇双倍期间，普通食物、工具果实和补给拾取得分翻倍。
- **护盾**：抵挡一次伤害，不叠加。贪吃蛇撞到边界或自身时，会消耗护盾并尝试自动转向相邻安全格；没有安全方向时仍结束本局。
- **飞机清屏炸弹**：清除敌弹，击毁普通敌机，对工具 Boss 造成 6 点伤害。
- **坦克战场炸弹**：清除敌方子弹、击毁场上敌坦克，保留地图墙体与基地。
- **贪吃蛇减速**：持续 8 秒，降低移动速度，给转向留出更多时间。

暂停期间，道具有效时间与持续效果均冻结。重新开局或切换游戏后，已经结束的任务不会重复发放奖励。任务结束时，游戏自动暂停并显示本次结算。

### 随时体验联动

没有任务运行时，在任意一款游戏里点击 **「联动演练」**，即可体验工具目标、补给和道具。小游戏与联动演练均无需配置模型或 API Key。

移动、射击或吃到道具来获得加成，操作方式与正常游戏相同。会话任务开始后，游戏会接入当前任务的进度；任务运行中或等待你的操作时，演练按钮暂不可用。

## 移动、缩放与极简模式

- **移动窗口**：拖动标题栏或点状手柄。
- **调整大小**：拖动窗口四边或四角。游戏画面保持比例，游戏速度保持不变；窗口缩窄后，游戏库折叠到顶部按钮中。
- **进入极简模式**：点击标题栏「极简模式」，收起游戏库、标题、分数、说明和工具栏，只保留游戏画面。
- **极简模式操作**：鼠标移入画面，浮现移动、暂停/继续、恢复完整模式和收起按钮。点击 `↗` 恢复完整窗口。触屏上始终显示这些必要控件。
- **继续游玩**：移动或缩放时游戏会暂停，调整完成后点击「继续」。切换完整/极简模式会保留本局进度，恢复完整模式时还原之前的窗口尺寸。

移动和缩放手柄也支持聚焦后用方向键操作。窗口会保持在浏览器视口内，浏览器缩小时自动调整位置与尺寸。

## 会话联动与进度保存

当前会话结束运行、需要审批或补充信息、会话状态不可用时，游戏会自动暂停。切出浏览器窗口或隐藏页面时也会暂停；回到游戏后手动继续。

会话停止运行的提示表示需要查看回复，不表示任务一定成功。极简模式下同样会显示需要返回会话处理的提示。

收起窗口保留当前页面内的游戏进度。切换游戏会重新开局，切换会话会清空本局战场；刷新页面会重置本局进度、窗口位置与尺寸，最高分仍保留在浏览器本地。浏览器禁止保存时，界面会提示最高分仅在本次打开期间保留。

## 卸载

执行以下命令，然后重启 Web profile：

```sh
dsh plugin --profile web remove dsh-whileplay
```

通过 npm 运行 Harness 的用户使用 `npx @deepseek-ai/dsh plugin --profile web remove dsh-whileplay`。卸载不会自动清除浏览器中保存的最高分。
