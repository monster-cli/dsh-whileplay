**把等待 AI 的时间，变成一小局。**

Whileplay 是 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的 Web 插件，把飞机大战、坦克大战和贪吃蛇带到聊天窗口旁。AI 调用工具时，游戏里会出现敌人或奖励目标；每完成一步任务，就有新的道具等你收集。

一边让 AI 继续工作，一边打一小局。需要你查看回复或处理审批时，游戏会自动暂停。

[立即安装](#快速开始) · [看看怎么玩](#三款游戏三种任务玩法) · [版本更新](https://github.com/monster-cli/dsh-whileplay/releases)

## 为什么试试玩一小局

- **任务进度参与玩法。** 工具调用变成飞机 Boss、精英坦克或奖励果实，完成的任务步骤变成补给，把当前会话的进展带进游戏。
- **游戏窗口随手摆放。** 支持拖动、缩放和极简模式，可以缩成只保留游戏画面的小窗。
- **随时回到正事。** 会话结束运行、等待审批或需要补充信息时自动暂停；回来后再继续这一局。
- **装好就能试玩。** 三款游戏都提供「联动演练」，无需配置模型即可体验；支持中文、英文界面及浅色、深色主题。

## 快速开始

需要已安装的 DeepSeek Harness Web profile，以及 Node.js `^22.19.0 || >=24.0.0` 和 npm。当前版本已在 Harness `0.2.1-alpha.4` 上验证，其他宿主版本尚未验证。

**1. 下载插件。** 获取 [dsh-whileplay-0.2.0.tgz](https://github.com/monster-cli/dsh-whileplay/releases/download/v0.2.0/dsh-whileplay-0.2.0.tgz)。

**2. 安装并启动。** 在安装包所在目录执行：

```sh
dsh plugin --profile web add ./dsh-whileplay-0.2.0.tgz
dsh web
```

已有 Harness Web 服务正在运行时，请安装后重启 Web profile。

<details>
<summary>没有全局 dsh 命令？使用 npx</summary>

```sh
npx @deepseek-ai/dsh plugin --profile web add ./dsh-whileplay-0.2.0.tgz
npx @deepseek-ai/dsh web
```

</details>

**3. 开始一小局。** 打开终端输出的页面，点击聊天输入框旁的 **「◈ 玩一小局」**，选择游戏，再点击「开始游戏」。没有任务运行时，也可以点击 **「联动演练」**，马上体验目标和道具。

## 三款游戏，三种任务玩法

| 游戏 | 经典玩法 | 工具调用带来的目标 | 完成一步任务后的补给 |
| --- | --- | --- | --- |
| **飞机大战** | 上下左右移动，自动射击 | 轰炸机、运输机、装甲机等小 Boss | 双发子弹、护盾、清屏炸弹 |
| **坦克大战** | 穿越砖墙与钢墙，射击敌坦克、守卫基地 | 需要命中三次的精英坦克 | 连发、护盾、战场炸弹 |
| **贪吃蛇** | 吃食物增长，避开边界和自己 | 带工具名称的限时奖励果实 | 双倍得分、护盾、减速 |

工具生成的目标按游戏规则参与本局，直到被击败、收集或离场。游戏胜负与任务执行相互独立。工具目标同时最多两个，密集调用依次入场。

### 操作

- **飞机大战**：方向键移动，也可在画布上拖动；自动发射子弹。
- **坦克大战**：方向键移动和转向，`Space` 射击。砖墙可击碎，钢墙不可破坏，双方子弹可以互相抵消。玩家有 3 条生命，生命耗尽或基地被击毁时结束。
- **贪吃蛇**：方向键转向，收集食物与奖励果实。

点击画布后即可使用键盘。窗口内也提供方向与射击按钮；按 `Escape` 收起游戏窗口。

### 接住道具，改变这一局

AI 每完成一步（Step），就会送来一份补给，拾取额外 +20 分。飞机道具向下飘落，坦克道具出现在可达的空闲通道，贪吃蛇道具出现在空白格。坦克与贪吃蛇的道具、奖励果实保留 12 秒。

| 道具 | 效果 |
| --- | --- |
| **双发 / 连发 / 双倍得分** | 分别增强飞机火力、坦克射速或贪吃蛇得分，持续 8 秒；重复拾取刷新时长。 |
| **护盾** | 抵挡一次伤害，不叠加。贪吃蛇会尝试转向相邻安全格；没有安全方向时仍结束本局。 |
| **清屏炸弹** | 飞机清除敌弹、击毁普通敌机，对 Boss 造成 6 点伤害；坦克清除敌弹和敌坦克，保留墙体与基地。 |
| **减速** | 贪吃蛇移动速度降低，持续 8 秒，给转向留出更多时间。 |

击落工具飞机 +100 分，击毁精英坦克 +200 分，吃到工具果实 +30 分并增长一格。贪吃蛇双倍得分期间，普通食物、工具果实与补给的拾取得分均翻倍。暂停期间，道具倒计时与加成时间一并冻结。

## 小窗游玩，随时回到会话

- **移动与缩放**：拖动标题栏或点状手柄移动窗口，拖动四边或四角调整大小。调整窗口时游戏暂停，点击「继续」即可恢复。
- **极简模式**：收起游戏库、标题和工具栏，只保留游戏画面。鼠标移入画面即可找到移动、暂停和恢复完整模式的按钮；触屏上始终显示这些控件。
- **自动暂停**：会话结束运行、需要审批或补充信息、状态不可用时暂停。切出浏览器窗口或隐藏页面也会暂停，回到游戏后手动继续。

收起窗口会保留当前页面内的进度。切换游戏或会话会重新开局，刷新页面会重置本局和窗口布局；最高分保存在当前浏览器中。任务结束时会显示本次结算，请返回会话查看回复。

## 常见问题

**需要配置模型或 API Key 吗？**

小游戏和「联动演练」都无需模型或 API Key，也不会额外发起模型请求。使用真实任务联动时，按 DeepSeek Harness 的要求配置并启动 AI 任务即可。

**演练按钮为什么不可用？**

当前会话正在执行任务或等待你的操作时，演练暂不可用。真实任务开始后，游戏会接入当前会话的进度。

**如何升级或卸载？**

升级时下载新版 `.tgz`，再次执行安装命令并重启 Web profile。卸载执行以下命令，然后重启 Web profile：

```sh
dsh plugin --profile web remove dsh-whileplay
```

通过 npm 运行 Harness 时使用 `npx @deepseek-ai/dsh plugin --profile web remove dsh-whileplay`。卸载不会自动清除浏览器中保存的最高分。
